# 久坐休息提醒（RestReminder）

一款 Windows 托盘小工具：连续久坐一段时间后，在屏幕右下角轻轻提醒你起身活动。
只做提醒——不强制休息、不锁屏、不打断工作。

## 它是怎么工作的

- 只在你在工位时累计「连续久坐时长」；起身离开（一段时间无操作、锁屏或睡眠）即清零重算。
- 连续久坐达到提醒阈值（默认 60 分钟）时，右下角弹出一张提示卡片，告诉你已经连续坐了多久。
- 卡片几秒后自动消失，不挡操作；鼠标悬停暂停倒计时，点击立即关闭。
- 一直没离开会按间隔温和地再提醒一次，越提醒越轻，永远不会强制你休息。
- 可选「手机热点在场检测」：电脑连着手机热点即视为在工位——适合两台电脑轮流办公、但手机一直放在工位的场景。

## 使用

1. 运行 `RestReminder.exe`，无需安装。
2. 常驻系统托盘：悬浮可看「已连续坐多久 · 今日累计」，双击打开设置。
3. 右键托盘图标：暂停提醒 / 重置本轮计时 / 设置 / 开机自启 / 退出。
4. 到点前 3 分钟有一条轻预告，到点弹出提示卡片；卡片会自动消失，不需要任何操作。

## 设置

- 提醒阈值、到点前预告、被忽略后的重申间隔
- 提示卡片停留时长、提醒提示音
- 多久无操作视为离开
- 在场检测方式：仅本机键鼠活动 / 或手机热点连接
- 开机自动启动

在设置窗口修改后立即生效；配置保存在 `%APPDATA%\RestReminder\config.txt`。

## 系统要求

Windows 10 / 11（.NET Framework 4.8 系统内置，无需额外安装）。

## 从源码构建

```bash
dotnet build -c Release RestReminder.csproj
# 产物：bin/Release/net48/RestReminder.exe
```
