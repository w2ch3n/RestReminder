# 久坐休息提醒（RestReminder）

一个运行在 **Windows 10/11** 上的常驻托盘小工具：在你**连续久坐**时友好地提醒你起来活动一下，防止一坐就是一整天。它只负责提醒，**从不强制休息**，不会打断你的工作节奏。

## 计时规则（久坐会话制）

与“工作 45 分钟 → 强制休息 5 分钟”的周期制不同，本应用跟踪的是**一次连续坐着的时间**：

1. **在场判定可选**：
   - 默认**只看本机键鼠操作**——键盘/鼠标有操作时，连续久坐计时持续累计；
   - 也可开启**手机热点在场检测**——联网电脑连着手机热点即视为“在工位”，适合两台电脑轮流工作（其中一台是封闭的涉密/内网机器）、但手机一直放在工位的情况。详见下文“在场检测（双机办公）”；
2. **离开即清零**：判定为“已离开”（无操作超过离开阈值、热点模式下手机热点断开），或发生**锁屏 / 睡眠 / 注销**，视为你已起身离开——本轮久坐清零，回来后重新开始。休息永远不需要“打卡完成”；
3. **到点温和提醒**：连续久坐达到提醒阈值（默认 60 分钟）时，右下角弹出一张**纯提示卡片**，显示“已连续坐多久”与一句建议：
   - 卡片**几秒后自动消失**（默认 5 秒，可在设置中调整），不打断操作；
   - **鼠标悬停会暂停倒计时**，方便你看完；**点击卡片立即关闭**；
   - 没有任何按钮——应用只做提醒，**不干涉你是否休息**；是否清零完全由“真正离开”检测决定；
   - 若你一直没离开，会按“重申间隔”（默认 15 分钟）再次弹出；第一次重申显示同样时长，之后第 2 次起缩短到 60%（不低于 3 秒），越提醒越轻；
4. **到点前预告**：在提醒点前 3 分钟先弹一条数秒后自动消失的轻提示，让你自然收尾，而不是被突然打断；
5. **计时可靠**：使用单调时钟，修改系统时间不影响计时；睡眠期间不计时；
6. **仅展示不施压**：托盘悬浮可查看“已连续坐多久 · 今日累计坐多久”，纯展示，从不弹窗催促。

## 在场检测（双机办公）

有些工位有两台电脑：一台联网、一台封闭（如涉密/内网机，不能装任何软件、不接任何设备）。在另一台电脑上工作时，联网电脑没有任何键鼠输入，默认会被判为“已离开”。

解决办法：把**手机热点**当作“人在工位”的信号——联网电脑本来就连着手机热点，热点在、人就在。

- **方式一（默认）**：仅检测本机键鼠活动。适合只有一台电脑的普通场景；
- **方式二**：检测本机键鼠活动 **或** 手机热点连接。适合双机办公：在另一台电脑上工作时，只要手机还连着，计时照常累计、到点照常提醒；午休/下楼把手机带走 → 热点断开超过宽限期 → 本轮清零。

实现细节：后台每 15 秒执行一次 `netsh wlan show interfaces` 读取当前 SSID（中英文系统通用，支持中文热点名，用 OEM 代码页解码）；热点短暂闪断有 60 秒宽限期，避免误清零；读取失败时沿用上一次结果。

> 说明：上厕所不拿手机时，这几分钟会被计入久坐（应用无法区分“在厕所”和“在另一台电脑前”，物理上没有可用信号）；真正离开（带走手机）才会清零。

## 功能

- ✅ 连续久坐计时 + 真实离开（无操作/锁屏/睡眠）自动清零
- ✅ 可选的**手机热点在场检测**（双机办公时，手机在工位即视为在场）
- ✅ 到点前轻预告（Toast，自动消失）+ 到点温和提醒弹窗
- ✅ 提醒卡片自动消失（悬停暂停、点击即关），无按钮、不干涉，永不强制休息
- ✅ 自定义：提醒阈值、提前预告、离开判定、重申间隔、弹窗停留时长（设置窗口或配置文件）
- ✅ 系统托盘常驻：悬浮显示状态，右键可 暂停提醒 / 重置本轮 / 设置 / 退出
- ✅ 开机自启（当前用户注册表 Run 键，免管理员权限）
- ✅ 提示音开关、今日累计久坐统计
- ✅ 单实例、无主窗口、不抢焦点、多显示器支持（弹窗出现在鼠标所在屏幕右下角）

## 技术栈

| 项 | 选择 | 理由 |
|---|---|---|
| 语言/框架 | C# + WinForms，目标 **.NET Framework 4.8** | Win10 预装 4.8，单 exe 零运行时依赖；`NotifyIcon` 托盘、`SystemEvents.SessionSwitch/PowerModeChanged` 锁屏睡眠事件、注册表自启全部原生支持 |
| 构建 | dotnet SDK（本仓库在 WSL2 上交叉编译出 exe） | `Microsoft.NETFramework.ReferenceAssemblies` 使 net48 可在 Linux 构建 |
| 配置 | `%APPDATA%\RestReminder\config.txt` | 纯文本 key=value，可手改 |
| 统计 | `%APPDATA%\RestReminder\stats.txt` | 今日累计久坐（跨天自动清零），仅托盘展示 |
| 自启 | `HKCU\...\CurrentVersion\Run` | 免管理员权限 |

## 构建

环境：任意安装了 .NET SDK（8.0+）的机器，包括 WSL2/Linux（交叉编译）。

```bash
dotnet build -c Release RestReminder.csproj
# 产物：bin/Release/net48/RestReminder.exe
```

在 Windows 上构建结果一致；在 Linux/WSL 上构建的 exe 同样可在 Windows 10 上直接运行。

## 使用

1. 将 `RestReminder.exe` 复制到任意目录（如 `C:\Program Files\RestReminder\`），双击运行。
2. 程序驻留托盘（蓝色对勾图标），悬浮可看“已连续坐 / 今日累计”。
3. 右键托盘图标 → **设置...** 修改阈值与节奏、开关开机自启与提示音。
4. 到点前会有数秒轻提示收尾；到点后右下角弹出提示卡片：
   - 卡片显示“已连续坐多久”，默认 5 秒后自动消失，不打断操作；
   - 鼠标悬停会暂停倒计时，点击卡片可立即关闭；
   - 没有任何按钮，应用不干涉你是否休息；
5. 真的起身离开（无操作超阈值、或锁屏/睡眠）后，本轮自动清零——应用知道你活动过了，不会再催。
6. 右键托盘图标 → **退出** 结束程序。

> 提示：若你经常长时间阅读/看视频而手不碰键鼠，请把“多久无操作视为已离开”调大（如 5~10 分钟），否则短暂停顿会被误判为“已离开”。
> 提醒卡片会自动消失，不会挡住操作；应用没有“强制休息”概念，也不会因你跳过提醒而惩罚。

## 配置文件

位置：`%APPDATA%\RestReminder\config.txt`

```
RemindMinutes=60          # 连续久坐多久提醒（分钟）
PreRemindMinutes=3        # 到点前提前预告（分钟，0=关闭）
LeaveMinutes=2            # 无操作多久视为已离开（分钟）
RepeatMinutes=15          # 被忽略后隔多久重申（分钟）
PopupSeconds=5            # 提醒弹窗停留时长（秒），悬停暂停、点击即关
AutoStart=false           # 开机自启
SoundOnRemind=true        # 提醒时播放提示音
PresenceMode=0            # 在场检测：0=只看本机键鼠；1=手机热点连着也算在场（可扩展更多值）
PresenceSsid=             # 手机热点名称（PresenceMode=1 时生效，支持中文）
PresenceGraceSeconds=60   # 热点断连宽限（秒），避免 Wi-Fi 闪断误清零
```

修改后需重启应用生效（设置窗口保存后即时生效）。旧版（1.0.x）配置中的 `WorkMinutes`/`IdleMinutes` 会自动迁移到新参数。

## 已知限制

- 需要 Windows 10（含 .NET Framework 4.8）或更新系统；
- “离开”默认依赖键盘/鼠标输入判定：静坐不动且无输入会被视为离开（可通过 `LeaveMinutes` 调整）；双机办公可开启**手机热点在场检测**来规避（需要联网电脑连着手机热点）；
- 热点模式下，不带手机短暂离开（如去洗手间）仍会计入久坐——缺少可区分“人在厕所”与“人在另一台电脑前”的物理信号；
- 弹窗样式为自绘圆角卡片，非系统通知（避免依赖通知中心权限与 Win10 通知策略）。
